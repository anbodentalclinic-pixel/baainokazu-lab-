# 場合の数ラボ

順列・組合せを「なぜその数字を書けるのか」から理解するための学習アプリです。スマホの片手操作を想定しています。

## 内容

- **数える**:紙に書く樹形図を画面の上で左から1列ずつ描く。どの○からも同じ本数の線が出ていれば掛け、本数がちがえば分けて足す。決める順番は自由で、順番を変えると図の形が変わる(6題)
- **重なり**:1つを回す・入れかえる・名前を付けかえて、同じものが何個重なるかを自分で確かめる(組合せ・同じ文字・円順列・じゅず順列・組分け・順序固定)。最短経路と重複組合せの置き換えもここ
- **確認**:問題集の赤チェックの問題(39〜76、118頁。73は図つき)を1手ずつ進む。答えるたびに樹形図が1列ずつ伸び、最後に図から式と公式の形が出る。20題
- **初見**:問題文を読んで最初の一手を選び、そのあと樹形図を1列ずつ描きながら答えまで進む。20題

## 公開方法(GitHub Pages)

1. 新しいリポジトリを作り、このフォルダの `index.html` `icon.png` `.nojekyll` `README.md` をアップロードする
2. Settings → Pages → Branch を `main` / `(root)` にして保存する
3. 表示されたURLをスマホで開き、「ホーム画面に追加」する

進み具合は端末のブラウザ内に保存されます。一度開けば、通信なしでも動きます(ページを開き直すときは通信が必要です)。
